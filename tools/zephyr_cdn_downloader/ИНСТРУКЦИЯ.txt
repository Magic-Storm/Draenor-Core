ОДИН ФАЙЛ
---------
  СТАРТ.bat

Всё остальное (.bat) просто открывает нужный пункт СТАРТ.


ТРЕБОВАНИЯ
----------
• Windows 10/11, Python 3.10+ в PATH (галочка "Add to PATH")
• ~60–100+ ГБ свободно в ЭТОЙ папке
• mapextractor / vmap4* / mmaps_generator рядом со СТАРТ.bat
  (из build\bin\RelWithDebInfo), если нужны карты для сервера


МЕНЮ СТАРТ.bat
--------------
  1  ВСЁ ДЛЯ СЕРВЕРА
     Data с CDN → долить пробелы (wow.tools) → починить → extract

  2  Собрать / докачать Data     (можно прерывать и запускать снова)
  3  Долить пробелы              (после 2; усечённые архивы Zephyr)
  4  Скачать exe/DLL + патч
  5  Починить ENCODING/ROOT      (если CascLib BAD_FORMAT)
  6  Extract                     (maps / vmaps / mmaps)
  7  Запустить клиент

Клиент = папка, где лежит СТАРТ.bat (client_path.txt пишется сам).
Не указывай чужой Midnight / другой WoW.


ПРОГРЕСС
--------
Пункты 1–3 пишут в это же окно. Лог конвертера также:
  _reconvert.log   (если запускали вручную)
Не запускай два конвертера параллельно.


ПОСЛЕ УСПЕХА
------------
  Data\data\data.000 … data.NNN + *.idx
  Wow-64.exe
  maps\  vmaps\  mmaps\   (после extract)

Папку _cdn_cache можно удалить, когда Data полная.


ЧАСТЫЕ ОШИБКИ
-------------
• Нет Python → поставь с Add to PATH, новое окно cmd
• Мало места → "No space left on device"
• Extract без Data → сначала 2, потом 3, потом 6
• Чужой клиент в client_path.txt → удали файл, снова СТАРТ.bat
